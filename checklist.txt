================================================================================
  비고
================================================================================

  재빌드 명령어
    ./gradlew clean bootJar

  서버 실행 (OpenAI + 커스텀 API Key 포함)
    OPENAI_API_KEY=sk-... APP_API_KEY=my-secret-key \
      java -jar build/libs/springai-0.0.1-SNAPSHOT.jar

  Ollama 서버 실행
    ollama serve

  로그 확인
    tail -f /tmp/springai-mcp.log
    tail -f ~/Library/Logs/Claude/mcp-server-springai-mcp.log

  REST API 테스트 (X-API-Key 기본값: local-dev-key)
    curl -X POST http://localhost:8080/api/tools/chat \
      -H "X-API-Key: local-dev-key" \
      -H "Content-Type: application/json" \
      -d '{"taskType":"SENSITIVE_DATA","message":"테스트"}'
