## 3. `04_Website_To_Figma_Implementation_List.md` (JSP→Figma WEB_CAPTURE) — 58건

### 3.1 Release 1 잔여 — 사람의 실측/시각 검수 대기 (5건)

- `quality-baseline.json`의 tolerance 필드가 아직 `null` — Figma Desktop에서 사람이 실측해야 확정 가능
- 색상·글꼴·radius·shadow, Bounding Box, `preview.png` 대조 — 코드 버그 3건은 이미 수정됐고 **재-import 재확인만 남음**
- Page Readiness/DOM·CSS Collector 등 모듈 분리 리팩터링 — 기능은 동작하나 구조 정리만 보류(의도적 후순위)

### 3.2 Release 2/3 스코프 — 착수 여부 자체가 미결정 (53건)

- 인증 세션 캡처 정식화(Secret 저장소, owner 권한 검증, 로그인 오탐 방지) — 9건
- SPA/동적 상태 캡처(hydration 판정, client-side route 감지 등) — 9건
- 반응형 멀티 viewport 캡처 — 8건
- 운영망 확장(멀티테넌트, 감사 로그, rate limit, PII 마스킹, 관리자 차단) — 15건 이상

이 항목들은 대부분 "결정 게이트"(승인/미승인) 단계이지 버그가 아니다. 착수 여부 자체가 별도
결정 필요.

## 5. `buildBoardFeature` 2개 문서 — 사실상 1건으로 수렴

`구현목록.md`의 미착수 12건과 `영향평가.md`의 `VAL-001`은 같은 문제를 가리킨다: input/select/
button 높이 일관성, pagination 수직 정렬을 **실제 브라우저에서 사람이 확인**해야 함. 핵심
생성기 로직(GAP-001~006)은 전부 구현 완료했고, 인앱 브라우저 세션이 주어지면 바로 닫을 수
있는 상태다. 첨부파일 스트리밍(EXC-001)은 의도적 제외, 권한/명명 규칙(DEC-001/002)은 별도
정책 결정 대기.

## 11. 공통 패턴

미구현 146건과 부분 진행 54건 중 상당수가 코드 버그가 아니라 다음 세 유형 중 하나다.

2. **스코프 자체가 미승인** — Release 2+, 운영망 확장
3. **대형 리팩터링의 후속 마일스톤** — M5/M6

실제로 "지금 당장 코드로 막힌" 항목은 R1-015, R6-050~058(Legacy Thymeleaf 대체), M2 Operation
migration 정도로 좁혀진다.
