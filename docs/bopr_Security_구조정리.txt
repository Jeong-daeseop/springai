  3. 요청 처리 Filter 체인 (web.xml 선언 순서)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  HTTP 요청 (*.do)
        │
        ▼
  ① CharacterEncodingFilter
  │    역할 : UTF-8 인코딩 강제 적용
  │    경로 : *.do
        │
        ▼
  ② HTMLTagFilter
  │    역할 : XSS 방어 — 모든 파라미터의 HTML 태그 제거
  │    클래스: egovframework.com.cmm.filter.HTMLTagFilter
  │    경로 : *.do
        │
        ▼
  ③ LoginPolicyFilter
  │    역할 : 로그인 전 비밀번호 만료/계정 잠금 정책 체크
  │    클래스: egovframework.com.uat.uap.filter.EgovLoginPolicyFilter
  │    경로 : /uat/uia/actionLogin.do (로그인 처리 URL만)
        │
        ▼
  ④ EgovSpringSecurityLoginFilter                      ← 핵심 인증 필터
  │    클래스: egovframework.com.sec.security.filter.EgovSpringSecurityLoginFilter
  │    경로 : *.do
  │
  │    [일반 로그인 흐름 - isRemotelyAuthenticated == null]
  │    1. /actionLogin.do 요청 확인
  │    2. 비밀번호 길이 검증 (8자 미만 or 20자 초과 → 로그인 화면 forward)
  │    3. LoginVO(id, password, userSe) 구성
  │    4. EgovLoginService.actionLogin(loginVO) → DB 인증 실행
  │    5. 인증 성공 시:
  │       - session.setAttribute("loginVO", loginVO)
  │       - session.setAttribute("isLocallyAuthenticated", "true")
  │       - UserDetailsService.loadUserByUsername(userId)
  │       - UsernamePasswordAuthenticationToken.authenticated() 생성
  │       - SecurityContextHolder에 SecurityContext 설정
  │       - HttpSessionSecurityContextRepository.saveContext() → 세션 저장
  │       - /main/Main.do 리다이렉트
  │    6. 인증 실패 시: 로그인 화면 forward + 에러 메시지
  │
  │    [SSO 로그인 흐름 - isRemotelyAuthenticated == "true"]
  │    1. session의 loginVOForDBAuthentication으로 DB 재조회
  │    2. 이후 동일하게 SecurityContext 설정 후 Main.do 리다이렉트
        │
        ▼

  사용자 조회 SQL
  ┌────────────────────────────────────────────────────────────────────────┐
  │  SELECT USER_ID, USER_NM, PASSWORD, 1 ENABLED, DEPT_ID               │
  │  FROM TN_USERS                                                         │
  │  WHERE USER_ID = ?                                                     │
  └────────────────────────────────────────────────────────────────────────┘

  권한 조회 SQL
  ┌────────────────────────────────────────────────────────────────────────┐
  │  SELECT A.SCRTY_DTRMN_TRGET_ID USER_ID, A.AUTHOR_CODE AUTHORITY       │
  │  FROM TN_EMPLYRSCRTYESTBS A, TN_USERS B                               │
  │  WHERE A.SCRTY_DTRMN_TRGET_ID = B.USER_ID                             │
  │  AND B.USER_ID = ?                                                     │
  └────────────────────────────────────────────────────────────────────────┘

  URL 권한 매핑 SQL (DB 동적 로딩)
  ┌────────────────────────────────────────────────────────────────────────┐
  │  SELECT a.ROLE_PTTRN url, b.AUTHOR_CODE authority                     │
  │  FROM TN_ROLEINFO a, TN_AUTHORROLERELATE b                            │
  │  WHERE a.ROLE_CODE = b.ROLE_CODE                                       │
  │  AND a.ROLE_TY = 'url'                                                │
  │  ORDER BY a.ROLE_SORT                                                  │
  └────────────────────────────────────────────────────────────────────────┘

  롤 계층 SQL
  ┌────────────────────────────────────────────────────────────────────────┐
  │  SELECT a.CHILD_ROLE child, a.PARNTS_ROLE parent                      │
  │  FROM TN_ROLES_HIERARCHY a                                             │
  │  LEFT JOIN TN_ROLES_HIERARCHY b ON (a.CHILD_ROLE = b.PARNTS_ROLE)    │
  └────────────────────────────────────────────────────────────────────────┘

  비밀번호 해시 방식
  ┌────────────────────────────────────────────────────────────────────────┐
  │  알고리즘 : SHA-256                                                    │
  │  Salt     : userId                                                     │
  │  인코딩   : Base64                                                     │
  │  구현체   : EgovFileScrty.encryptPassword()                            │
  └────────────────────────────────────────────────────────────────────────┘

  세션 매핑 클래스 (EgovSessionMapping)
  ┌────────────────────────────────────────────────────────────────────────┐
  │  ResultSet → LoginVO 변환                                              │
  │    user_id   → loginVO.id                                             │
  │    password  → loginVO.password                                       │
  │    user_nm   → loginVO.name                                           │
  │    dept_id   → loginVO.orgnztId / orgnztNm                            │
  │  → EgovUserDetails(userId, password, enabled, loginVO) 생성           │
  └────────────────────────────────────────────────────────────────────────┘

  BoprSecurityConfig.java                      ← 프로젝트 보안 진입점
    위치: egovframework.bopr.config
    @Configuration
    @Import(EgovSecurityConfiguration.class)
          │
          ▼
    EgovSecurityConfiguration                  ← eGovFrame RTE 5.0.0 제공
    @EnableWebSecurity
          │
          ├── securityConfig 빈 주입 (context-security.xml에서 선언)
          ├── HttpSecurity 구성 (URL 접근 제어, 세션, 헤더)
          ├── JdbcDaoImpl 구성 (UserDetailsService, 사용자/권한 SQL)
          └── FilterSecurityInterceptor (URL 권한 동적 적용)

  ※ XML <bean>으로 EgovSecurityConfiguration을 직접 선언하면
     Spring Security 6.5의 @Import 처리 중 BootstrapMethodError 발생
     → BoprSecurityConfig Java Config를 통해 @Import 방식으로 우회
