3. 문제 항목 상세
--------------------------------------------------------------------------------

[javaConfig — eGovFrame 4.3 사용 불가 ❌]

  현재 생성 코드는 Spring Security 6.x 전용 API만 사용.

  현재 생성 코드 (Security 6.x — eGovFrame 5.0):
  ┌──────────────────────────────────────────────────────────────────────┐
  │  @Configuration                                                      │
  │  @EnableWebSecurity                                                  │
  │  public class EgovSecurityConfig {                                   │
  │      @Bean                                                           │
  │      public SecurityFilterChain filterChain(HttpSecurity http) {    │
  │          http                                                        │
  │              .authorizeHttpRequests(auth -> auth                     │
  │                  .requestMatchers("/css/**").permitAll()             │
  │              )                                                       │
  │              .csrf(csrf -> csrf.ignoringRequestMatchers("/api/**")); │
  │          return http.build();                                        │
  │      }                                                               │
  │  }                                                                   │
  └──────────────────────────────────────────────────────────────────────┘

  4.3에서 필요한 방식 (Security 4.x — WebSecurityConfigurerAdapter):
  ┌──────────────────────────────────────────────────────────────────────┐
  │  @Configuration                                                      │
  │  @EnableWebSecurity                                                  │
  │  public class EgovSecurityConfig                                     │
  │          extends WebSecurityConfigurerAdapter {   ← 5.0에서 삭제    │
  │                                                                      │
  │      @Override                                                       │
  │      protected void configure(HttpSecurity http) throws Exception {  │
  │          http                                                        │
  │              .authorizeRequests()                ← 5.0: authorizeHttpRequests() │
  │                  .antMatchers("/css/**").permitAll()  ← 5.0: requestMatchers()  │
  │                  .anyRequest().authenticated()                       │
  │              .and()                              ← 5.0: Lambda DSL  │
  │              .formLogin()                                            │
  │                  .loginPage("/uat/uia/egovLoginUsr.do")              │
  │              .and()                                                  │
  │              .csrf().ignoringAntMatchers("/api/**"); ← API명 상이   │
  │      }                                                               │
  │  }                                                                   │
  └──────────────────────────────────────────────────────────────────────┘

  API 변경 대조표:
    4.3 API                    →  5.0 API
    ─────────────────────────────────────────────────────
    WebSecurityConfigurerAdapter  삭제 (SecurityFilterChain Bean으로 대체)
    authorizeRequests()           authorizeHttpRequests()
    antMatchers()                 requestMatchers()
    .and() 체이닝                 Lambda DSL (.formLogin(form -> form...))
    csrf().ignoringAntMatchers()  csrf(csrf -> csrf.ignoringRequestMatchers())
    configure(HttpSecurity http)  filterChain(HttpSecurity http) @Bean

[contextSecurity — eGovFrame 4.3 부분 호환 ⚠️]

  XML 네임스페이스 구조 자체는 거의 동일하나,
  참조 eGovFrame 런타임 클래스명이 버전별로 패키지 경로가 다를 수 있음.

  현재 생성 코드 (eGovFrame 5.x 기준 클래스명):
    egovframework.rte.fdl.security.intercept
        .EgovReloadableFilterInvocationSecurityMetadataSource
    egovframework.rte.fdl.security.userdetails
        .EgovUserDetailsHelper
    egovframework.rte.fdl.security.userdetails
        .EgovAuthenticationSuccessHandler
    egovframework.rte.fdl.security.userdetails
        .EgovAuthenticationFailureHandler
    egovframework.rte.fdl.security.userdetails
        .EgovAccessDeniedHandler

  → eGovFrame 4.3 프로젝트에서는 위 클래스가 존재하지 않거나
    패키지 경로가 상이할 수 있으므로 직접 확인 후 수정 필요.

------------------------------------------------------------------------

[roleHierarchy — eGovFrame 5.0 최신 Deprecation 주의 ⚠️]

  현재 생성 코드:
    RoleHierarchyImpl impl = new RoleHierarchyImpl();
    impl.setHierarchy(hierarchy.toString());   ← Security 6.2+에서 Deprecated

  Spring Security 6.2+ 권장 방식:
    RoleHierarchyImpl impl = RoleHierarchyImpl.fromHierarchy(hierarchy.toString());

  → eGovFrame 5.0이 Spring Security 6.2 이상을 사용하는 경우 경고 발생.
    동작은 하지만 향후 버전에서 제거될 수 있음.

------------------------------------------------------------------------

[javaConfig — eGovFrame 5.0 Deprecated API 사용 ⚠️]

  현재 생성 코드에서 Security 6.x에서 Deprecated된 API 2개 사용:
    FilterSecurityInterceptor   → AuthorizationFilter 로 대체 권장
    AccessDecisionManager       → AuthorizationManager 로 대체 권장

  → 동작에는 문제 없으나 컴파일 경고 발생.
    eGovFrame 공통 모듈(EgovReloadableFilterInvocationSecurityMetadataSource)이
    여전히 FilterSecurityInterceptor 기반이므로 현재는 불가피한 선택.

--------------------------------------------------------------------------------

  eGovFrame 4.3 프로젝트:
    ✅ webXmlFilter      → 그대로 사용 가능

    ❌ javaConfig        → 사용 불가 (WebSecurityConfigurerAdapter 방식으로 재작성 필요)
    ✅ userDetailsService → 그대로 사용 가능
    ✅ roleHierarchy     → 그대로 사용 가능 (setHierarchy() 4.3도 동일)

  eGovFrame 5.0 프로젝트:
    ✅ webXmlFilter      → 그대로 사용 가능
    ✅ contextSecurity   → 그대로 사용 가능
    ✅ securityMapper    → 그대로 사용 가능
    ✅ javaConfig        → 사용 가능 (Deprecated API 경고는 발생)
    ✅ userDetailsService → 그대로 사용 가능
    ✅ roleHierarchy     → 사용 가능 (setHierarchy() Deprecation 경고 가능)
    ✅ loginPage         → 그대로 사용 가능

5. 개선 방향 — egovVersion 파라미터 추가
--------------------------------------------------------------------------------

  현재 메서드 시그니처:
    getSecurityTemplate(String securityType, String packageName)

  개선 후 메서드 시그니처 (안):
    getSecurityTemplate(String securityType, String packageName, String egovVersion)

  분기 로직:
    case "javaconfig":
        if ("4.3".equals(egovVersion)) → javaConfig43(pkg)   // WebSecurityConfigurerAdapter
        else                           → javaConfig50(pkg)   // SecurityFilterChain Bean (현재)

    case "rolehierarchy":
        if ("5.0".equals(egovVersion) && securityVersion >= 6.2)
                                       → roleHierarchy50New(pkg)  // fromHierarchy()
        else                           → roleHierarchy(pkg)       // setHierarchy() (현재)

  추가 필요 private 메서드:
    javaConfig43(String pkg)       → WebSecurityConfigurerAdapter 방식
    javaConfig50(String pkg)       → SecurityFilterChain Bean 방식 (현재 javaConfig)
    roleHierarchy50New(String pkg) → fromHierarchy() 방식

  추가 securityType 후보 (4.3 전용):
    "javaConfig43"  → WebSecurityConfigurerAdapter 방식 명시적 요청
