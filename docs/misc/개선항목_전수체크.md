## 🔴 Critical — 즉시 수정 필요 (3건)

### C-1. Path Traversal — 임의 파일 쓰기 가능

- **위치**: `src/main/java/com/krdevops/springai/service/CodeService.java:50-56`
- **문제**: `saveGeneratedCode(filePath, code)`에서 `filePath` 검증 없이 `Paths.get(filePath)` 사용
  - REST API(`ToolApiController:44`)를 통해 `body.get("filePath")` 값이 그대로 전달됨
  - 공격자가 `../../etc/crontab` 같은 경로를 전송하면 서버 어디든 파일 쓰기 가능
  - `EgovDocumentServiceImpl`에는 `getCanonicalPath()` 방어가 있으나 `CodeService`에는 없음
- **수정 방향**:
  ```java
  Path base = Paths.get(egovProperties.getOutput().getBasePath()).toRealPath();
  Path target = base.resolve(filePath).normalize();
  if (!target.startsWith(base)) throw new SecurityException("허용 범위 밖 경로");
  ```

### C-2. SSRF (Server-Side Request Forgery)

- **위치**: `src/main/java/com/krdevops/springai/service/RagService.java:184-212`
- **문제**: `ingestUrl(url, docId)`에서 사용자 입력 URL을 검증 없이 `HttpClient`로 요청
  - `http://169.254.169.254/latest/meta-data/` (AWS 메타데이터) 등 내부 리소스 접근 가능
  - 내부 네트워크 IP 대역(`10.x`, `172.16-31.x`, `192.168.x`, `127.0.0.1`) 탐색 가능
- **수정 방향**:
  - 허용 도메인 화이트리스트 적용 또는 사설/링크로컬 IP 대역 블랙리스트 차단
  - 최소한 `InetAddress.getByName(host).isSiteLocalAddress()` 체크 추가

### C-3. CORS 전체 개방 — EgovChatSessionController

- **위치**: `src/main/java/com/krdevops/springai/chat/controller/EgovChatSessionController.java:20`
- **문제**: `@CrossOrigin(origins = "*")` — 모든 도메인에서 세션 생성/삭제/수정 API 호출 가능
  - `EgovDocumentController`는 `${app.allowed-origins:http://localhost:8080}`으로 이미 수정되었으나 이 컨트롤러는 누락
- **수정 방향**:
  ```java
  @CrossOrigin(origins = "${app.allowed-origins:http://localhost:8080}")
  ```

## 🔴 High — 빠른 수정 권장 (5건)

### H-1. TOCTOU 경합 조건 — isProcessing 체크

- **위치**: `src/main/java/com/krdevops/springai/chat/service/impl/EgovDocumentServiceImpl.java:73-78`
- **문제**: `isProcessing.get()` 체크 후 `isProcessing.set(true)` 사이에 경합 조건 존재
  - 두 요청이 동시에 `loadDocumentsAsync()` 호출 시 둘 다 `false`를 읽고 동시 인덱싱 시작 가능
- **수정 방향**:
  ```java
  if (!isProcessing.compareAndSet(false, true)) {
      log.info("이미 인덱싱 중입니다.");
      return CompletableFuture.completedFuture(0);
  }
  ```

### H-2. ClassCastException — topK 파라미터

- **위치**: `src/main/java/com/krdevops/springai/controller/RagController.java:62,88`
- **문제**: `(int) body.get("topK")` — Jackson이 JSON 숫자를 `Long`으로 파싱할 경우 `ClassCastException` 발생
  - `@RequestBody Map<String, Object>` 사용 시 숫자 타입이 값 범위에 따라 `Integer` 또는 `Long`이 됨
- **수정 방향**:
  ```java
  int topK = body.containsKey("topK")
      ? ((Number) body.get("topK")).intValue()
      : 3;
  ```

### H-3. 입력 검증 부재 — ToolApiController

- **위치**: `src/main/java/com/krdevops/springai/controller/ToolApiController.java:32-79`
- **문제**: 모든 엔드포인트가 `Map<String, String>`으로 받고 `body.get("key")` 검증 없이 서비스에 전달

- **수정 방향**: 필수 파라미터 null 체크 추가 또는 타입 안전한 DTO + `@Valid` 적용

### H-4. 쿼리 압축 동기 블로킹

- **위치**: `src/main/java/com/krdevops/springai/chat/config/rag/transformers/EgovCompressionQueryTransformer.java:86-91`
- **문제**: `compress()`에서 `ollamaChatClient.prompt()...call().content()` 동기 호출
  - SSE 스트리밍 파이프라인 진입 전 HTTP 요청 스레드 블로킹 (Ollama 1-5초 응답 시간)


### H-5. 문서 인덱싱 순차 처리

- **위치**: `src/main/java/com/krdevops/springai/chat/service/impl/EgovDocumentServiceImpl.java:108-135`
- **문제**: `loadDocumentsAsync()` 내 파일별 순차 `extractContent() → ragService.ingestText()` 처리
  - 비동기 Executor에 넘겼으나 내부는 단일 스레드 순차 처리
  - 파일 100개 × 파일당 2초 = 200초 소요 가능
- **수정 방향**:
  ```java
  List<CompletableFuture<Void>> futures = docFileMap.entrySet().stream()
      .map(entry -> CompletableFuture.runAsync(() -> processFile(entry), executor))
      .toList();
  CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
  ```
  단, 동시성 제한(Semaphore 또는 ThreadPool 크기)으로 메모리 폭증 방지 필요
