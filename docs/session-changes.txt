8. 빌드 오류 수정 이력
--------------------------------------------------------------------------------

오류 1: spring-ai-advisors-vector-store 의존성 미존재
  → build.gradle에서 제거

오류 2: org.springframework.ai.rag.* 패키지 미존재 (Spring AI 2.0.0-M6)
  영향 파일:
    - EgovRagConfig.java
    - EgovCompressionQueryTransformer.java
    - EgovSessionAwareChatServiceImpl.java
  수정 방법:
    - EgovRagConfig: RAG advisor 패턴 제거, ChatClient 빈만 유지
    - EgovCompressionQueryTransformer: Query 객체 → String 입출력으로 변경,
      ChatClient 직접 호출로 쿼리 압축 구현
    - EgovSessionAwareChatServiceImpl: VectorStoreDocumentRetriever 제거,
      RagService.buildRagContext() 결과를 system prompt로 주입

오류 3: ChatMemory.DEFAULT_CONVERSATION_ID 상수 미존재
  영향 파일:
    - SessionContext.java
    - EgovOllamaChatController.java
  수정: "default" 리터럴로 교체

오류 4: ChatClientRequestSpec.options() 타입 불일치
  원인: Spring AI 2.0.0-M6의 options()는 ChatOptions.Builder를 받음
         (ChatOptions 인스턴스 불가)
  영향 파일:
    - EgovCompressionQueryTransformer.java
    - EgovSessionAwareChatServiceImpl.java
  수정: ChatOptions.builder()...build() → ChatOptions.builder()... (build() 제거)

오류 5: jackson-datatype-jsr310 미존재
  수정: build.gradle에 의존성 추가
