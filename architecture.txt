--------------------------------------------------------------------------------
  LLM 라우팅 대상
--------------------------------------------------------------------------------

  Claude  (외부)
    - 역할: 코드 생성, 고품질 작업
    - 연결: SSE (Claude Desktop via mcp-remote)
    - 모델: Claude Sonnet / Opus

  OpenAI  (외부)
    - 역할: 분류/요약, 단순 조회 (비용 절감)
    - 연결: REST API
    - 모델: gpt-4o-mini

  Ollama  (사내)
    - 역할: 민감 데이터 처리 (외부 전송 금지)
    - 연결: localhost:11434
    - 모델: mistral (기본) / codellama / llama3
    - 임베딩: nomic-embed-text (RAG Vector Store 전용)

--------------------------------------------------------------------------------
  MCP Tool 목록 (Claude Desktop 노출)
--------------------------------------------------------------------------------

  DateTimeTool
    - getCurrentDateTime(timezone)     : 현재 날짜/시간 조회
    - celsiusToFahrenheit(celsius)     : 섭씨 → 화씨 변환

  SchemaReaderTool
    - getTableList(database)           : DB 테이블 목록 조회
    - getTableSchema(database, table)  : 테이블 컬럼 상세 조회

  EmployeeTool
    - getEmployeeList(keyword)         : 직원 목록 조회
    - getEmployee(emplyrId)            : 직원 단건 조회
    - createEmployee(...)              : 직원 등록
    - updateEmployee(...)              : 직원 수정
    - deleteEmployee(emplyrId)         : 직원 삭제

  CodeSaverTool
    - saveGeneratedCode(filePath,code) : 생성된 소스 파일 저장
    - checkOutputDirectory(baseDir)    : 출력 디렉터리 확인

  CodeTemplateTool
    - (eGovFrame 5.x 소스 자동 생성 관련 Tool)

--------------------------------------------------------------------------------
  REST API 엔드포인트
--------------------------------------------------------------------------------

  인증: X-API-Key 헤더 필수 (/sse, /mcp/** 제외)

  [MCP Tool API]
  POST /api/tools/getTableList       { database }
  POST /api/tools/getTableSchema     { database, tableName }
  POST /api/tools/saveGeneratedCode  { filePath, code }
  POST /api/tools/getEmployee        { emplyrId }
  POST /api/tools/getEmployeeList    { keyword }
  POST /api/tools/chat               { taskType, message }
                                       → CLASSIFICATION / SIMPLE_QUERY → OpenAI
                                       → SENSITIVE_DATA                → Ollama
                                       → CODE_GENERATION               → 오류 (Claude 사용)

  [RAG API]
  POST /api/rag/ingest               { docId, content, type }
                                       type: document / source_code / history
  POST /api/rag/ingest/directory     { directoryPath }  ← .java 파일 일괄 임베딩
  POST /api/rag/search               { query, topK }    ← 유사 문서 검색
  POST /api/rag/chat                 { query, taskType, topK }
                                       → Vector Store 검색 → LLM 컨텍스트 전달

--------------------------------------------------------------------------------
  RAG 사용 시나리오
--------------------------------------------------------------------------------

  1. eGovFrame 문서 검색
       /api/rag/ingest  → "egov-login" 문서 등록
       /api/rag/chat    → "표준프레임워크 로그인 처리 방법" 질의 → 문서 기반 답변

  2. 기존 소스코드 참조 생성
       /api/rag/ingest/directory → /my-project/src 전체 임베딩
       /api/rag/chat             → "우리 프로젝트 코딩 스타일로 CRUD 생성"

  3. 대화 히스토리 기반 추천
       /api/rag/ingest → "history-20260516" 생성 이력 등록
       /api/rag/chat   → "직원 관련 소스 생성" → 이전 패턴 재활용

--------------------------------------------------------------------------------
  실행 방법
--------------------------------------------------------------------------------

  1. Docker 컨테이너 시작
       docker start egov-mysql
       docker start redis-stack

  2. Ollama 시작
       ollama serve
       ollama pull nomic-embed-text   # 최초 1회

  3. 서버 빌드 및 실행
       ./gradlew clean bootJar
       OPENAI_API_KEY=sk-... APP_API_KEY=my-secret-key \
         java -jar build/libs/springai-0.0.1-SNAPSHOT.jar

  4. Claude Desktop 재시작
       → mcp-remote가 자동으로 http://localhost:8080/sse 연결

  5. RedisInsight (Vector Store 모니터링)
       http://localhost:8001
